# Sales Tools Portal

เว็บไซต์หน้าเดียวแบบเมนูสารบัญ ที่รวมหลายเครื่องมือไว้ในหน้าเดียว

## Included tools

- Email Tool
- Customer Search
- Meeting Report

## Structure

- `index.html` — เว็บหลักแบบ single-page portal

## Deploy

อัปโหลดไฟล์นี้ขึ้น GitHub Pages หรือ static hosting ได้ทันที

- เพิ่มปุ่ม Clear ข้อมูลใน Email Tool, Customer Search และ Meeting Report
- เพิ่ม Add/Update/Delete และ Export CSV ใน Customer Search สำหรับอัปเดตรายชื่อลูกค้าในอนาคต
